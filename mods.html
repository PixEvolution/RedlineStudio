🔒 Age brackets → private

Accounts from before Sept 25 still carry their age bracket on the PUBLIC account record until they visit again. This moves every remaining one into the private ages records at once. Needs the matching rules pasted first. Idempotent — running it again just finds nothing left to move. Accounts with no uid stamp can't be moved from here (no login to key on); they keep migrating themselves on their next visit.

🧱 Game cards

The list pages read a light cards collection so phones open instantly. This button builds (or rebuilds) a card for every existing game — run it ONCE after the cards update goes live. Safe to run again: it just rewrites the same cards.

What you can do from here (and from any game page)

On any game's page you get a 🛡 row: unlist/relist, re-rate, or delete it. Comments and forum posts grow a mod ✕. Removing a whole ACCOUNT stays deliberate, console-only work: Firebase console → Firestore → users → delete that doc, then Authentication → that user → delete. Handing out or removing mod status is console-only too: the mods collection, one doc per uid — the site itself can never write it.
