Games

Made by players, published in the Studio.

RedlineStudio is a free browser arcade and a game-making studio in one. Every machine below was built by a player in the Studio — a block-and-script editor where your first game takes five minutes and no code — and published straight to this floor: real cabinets with seats, lines, live watch windows and high-score tables. The collection starts with the Museum: fifty-seven playable remakes covering video game history from 1947 to 1982, each running with its real hardware's limits, each open source to learn from.
