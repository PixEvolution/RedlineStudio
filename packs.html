🎨 Emergence Sprite Packs

Like texture packs: player-made pixel trees, rocks, plants, creatures, tools and guns, buildings and ship looks for Emergence. They change how things look, never how the game plays. Download one, then drag the file onto the game window (or Sprite Packs → IMPORT). The game can also browse and download these itself: Sprite Packs → BROWSE ONLINE.

Share a pack

In the game: main menu → SPRITE PACKS → SHARE FILE on your pack. The files live in Documents\Emergence Sprite Packs. Pick yours here. Max 6 MB.
